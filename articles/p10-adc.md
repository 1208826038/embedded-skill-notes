# ADC 模拟数字转换：采样保持与 BMS 高压精度

## 一、引言：差 2mV 就可能误断高压

BMS 软件里最让人提心吊胆的一行判断大概是：`if (cellVoltage[i] > OVERVOLT_THRESHOLD)`。阈值是 4.25V，可如果你的 ADC 采样偏了 5mV，本该正常的电芯被判定过压→系统降功率甚至断高压；反过来，本该过压的电芯被"读低"了，热失控风险被掩盖。**在动力域，ADC 不是"大概量一下"的感官，而是安全决策的眼睛。** 整车厂对单体电压采样的要求常是 ±2mV 量级的绝对精度，这比普通 MCU 内置 ADC 的"分辨率"概念严得多。

我见过一个真实案例：某项目低压采样一切正常，唯独总压（几百伏）采样系统性偏低 0.3%。排查一圈，最后发现是高压分压电阻网络的输入阻抗与 ADC 采样电容不匹配，采样周期又设得太短，内部采样电容根本没充满——一个"建立时间"的疏忽，让整车 SOC 估算天天飘。

## 二、核心原理：SAR 与 Σ-Δ，以及"采样保持"这一秒

### 2.1 两种主流架构

- **SAR（逐次逼近寄存器）ADC**：中速中精度，最常见于 MCU 内置 ADC。原理像"天平称重"——从最高位开始，逐位拿参考电压的一半去比，N 位就比较 N 次，位数越多转换越久。适合多通道、中等精度（10/12/16bit）的通用采样。
- **Σ-Δ（Sigma-Delta）ADC**：高精度、低速，靠过采样 + 噪声整形 + 数字滤波，能把量化噪声推到带外，实现 20+ 位有效精度。常见于称重、音频、以及部分高精度电池监控前端。

### 2.2 采样保持（S/H）：最容易被忽视的一瞬

ADC 不能"边看边转"，它先要用**采样保持电路**把外部电压"冻住"：开关闭合，外部信号给内部采样电容充电（这就是**建立时间 Settling Time**）；充到足够准后开关断开，转换阶段才开始。整个过程可以拆成：

```
[ 采样保持 S/H ]  →  [ 转换 Conversion ]  →  [ 结果锁存 ]
   ↑ 建立时间            ↑ 位数决定时长
```

**类比**：采样保持像用杯子接水——你必须在"关龙头"前让杯子里的水位和外部水池齐平（建立时间达标）。如果水流慢（输入阻抗大）而你急着关龙头（采样周期太短），杯子没接满，测出来的就是偏低的"半杯水"。

### 2.3 量化与精度要素

- 分辨率：最小量化步长 `= Vref / 2^N`。12 位、Vref=3.3V → 步长约 0.8mV。
- 但**分辨率 ≠ 精度**。精度还受 Vref 稳定性、INL/DNL（积分/差分非线性）、噪声、建立时间、通道串扰共同决定。12 位 ADC 若 Vref 漂了 1%，绝对误差可能远大于一个步长。

## 三、帧格式 / 时序与配置（逐字段）

### 3.1 单次转换时间构成（逐字段）

| 阶段/参数 | 含义 |
|------|------|
| 采样阶段 (S/H) | 开关闭合，外部给采样电容充电，需 ≥ 建立时间才准 |
| 转换阶段 | SAR 逐位比较（或 Σ-Δ 调制），位数越多越久 |
| 触发源 | 软件触发 / 定时器触发 / 外部事件（硬件触发免抖动） |
| 分辨率 | 位数(10/12/16)，最小步长 = Vref/2^N |
| 采样率 | 每秒可完成转换次数 |
| Vref | 参考电压，决定满量程与精度基准 |
| 建立时间 | 采样电容充电达标所需时间，< 它则精度降 |

### 3.2 BMS 高压采样链路（文字描述）

电池单体/总压 → 分压电阻网络（把几百伏降到 MCU 可承受范围）→ RC 滤波/运放跟随 → 多路 MUX（轮流选通各通道）→ ADC 采样。MUX 切换后，信号需重新稳定（开关建立时间），否则会"串入前一路电压"。

### 3.3 配置代码片段（ADC + 硬件触发 + DMA，伪代码）

```c
/* BMS 高压采样：定时器触发 + DMA 搬运，零 CPU 干预、低抖动 */
ADC_Init(ADC0,
    .resolution = 12,            // 12 位
    .vref       = VREF_3V3,      // 外部基准，稳！
    .sample_time = 64_CYCLES);   // 关键！给足建立时间
ADC_ChannelSeq(ADC0, .ch = {V_PACK, V_CELL1, V_CELL2, V_TEMP},
    .scan = ENABLE);             // 扫描模式顺序采样
ADC_TriggerConfig(ADC0, .src = TIMER3_TRGO); // 由定时器硬件触发
ADC_DMAConfig(ADC0, .buffer = g_adcBuf, .size = 4,
    .mode = CIRCULAR);            // 循环搬，CPU 不介入

/* 内部校准：上电做一次 offset / gain 校准 */
ADC_Calibrate(ADC0, .type = OFFSET_GAIN);
/* 软件滤波：去极值平均，抑制偶发干扰 */
uint16_t filtered = MedianAverage(g_adcBuf, 8);
```

要点：**硬件触发 + DMA** 让采样时刻完全由定时器决定，免除了"软件启动→中断响应"的抖动，对周期性高压采样至关重要。

## 四、BMS 场景：高压精度怎么"抠"出来

BMS 对 ADC 的要求远超普通工业：

1. **建立时间必须满足**：采样开关闭合后电容需充满，采样周期太短→未充满→系统性偏低。这点在高压分压网络（输入阻抗大）上尤其致命。
2. **参考电压稳定**：用外部精密基准而非芯片内部 LDO；Vref 一漂，所有通道绝对精度跟着漂。
3. **内部 offset/gain 校准**：上电或定期做两点校准，消除零位与增益误差。
4. **通道顺序避开串扰**：相邻通道切换留足够采样时间，别让高压通道紧挨着低压通道快速轮询。
5. **硬件 + 软件双重滤波**：RC/运放跟随滤高频噪声，软件做中值+平均抑制毛刺。
6. **温度影响**：NTC 温度采样本身也走 ADC，温漂要建模补偿。

总压与单体电压都要求 mV 级精度——因为这直接决定一致性判断、均衡决策、SOH（健康度）估算是否可靠。

### 4.1 INL/DNL 与噪声：分辨率的"隐藏天花板"

即便 Vref 完美、建立时间充足，ADC 仍有**非线性误差**：INL（积分非线性）描述实际转换曲线偏离理想直线的最大偏差，DNL（差分非线性）描述相邻码宽与理想 1 LSB 的偏差。若 DNL 超过 1 LSB，可能出现"丢码"（missing code），某段输入电压无论怎么变都给出同一个数字。选型时 BMS 前端 ADC 的 INL 必须远小于目标精度（例如目标 ±2mV，INL 应控制在 1 LSB 以内）。

噪声则来自电源纹波、地弹、数字电路耦合。对策除硬件滤波外，软件常用**过采样 + 平均**：以高于奈奎斯特的速率采样再平均，等效提升有效位数（ENOB）。注意平均只能压随机噪声、不能修正系统性偏差（偏置/增益）。

### 4.2 多通道扫描与 MUX 串扰的工程细节

BMS 高压采样常是"一个 ADC + 外部多路 MUX"或"监控 IC 内置 MUX"。扫描模式下通道快速切换，每切一次，采样电容要重新跟踪新通道电压。若切换后立刻开始采样，前一路的电荷会通过开关寄生电容"串"到后一路，造成相邻通道相关性误差。工程上要么在通道间插入足够建立时间，要么用"虚采样"（先采一次丢弃再采有效值）。另外高压通道与低压/温度通道交替时，注意驱动能力差异导致的建立时间不同，别用同一采样参数一刀切。

## 五、常见坑与调试手段

1. **采样周期 < 建立时间 → 精度系统性偏低**：最经典的坑。现象是"所有通道都朝一个方向偏"。用示波器看采样电容充电曲线，或干脆把 `sample_time` 调大验证是否回归。
2. **输入阻抗不匹配**：高压分压电阻太大（为降功耗）导致源阻抗高，采样电容充不满。对策：前端加运放电压跟随器，或延长采样时间。
3. **MUX 切换未留建立时间 → 通道串扰**：某路电压"混入"相邻路。检查扫描序列中每通道的采样间隔，必要时在切换后插空闲采样周期。
4. **Vref 不稳/噪声**：用示波器量 Vref 引脚纹波；换外部基准、加去耦电容。
5. **参考通道与信号通道温度不同**：校准只做一次，温漂后失准。做温度补偿或定期重校准。

## 六、面试高频要点

- **采样周期太短会怎样？** → 内部采样电容未充满→量化值偏低/不准，系统性误差，且可能引入通道间串扰。
- **Vref 不稳对精度影响？** → 量化步长与满量程随 Vref 漂移，绝对精度直接下降；故 BMS 用外部精密基准。
- **分辨率 12 位就一定准吗？** → 不一定。精度还受 Vref、INL/DNL、噪声、建立时间、校准影响；分辨率只是"能分多少级"。
- **硬件触发 + DMA 的价值？** → 定时精确、零 CPU 干预、无中断抖动，特别适合周期性高压采样。
- **多路高压采样为何要注意 MUX 开关建立时间？** → 切换后信号需稳定才能采样，否则串入前一路电压，导致误判。
