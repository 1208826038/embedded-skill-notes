# PWM / ICU 定时器接口：从死区到输入捕获

## 一、引言：半桥里的"生死 50 纳秒"

凌晨三点，台架上那台 800V 电驱控制器又冒烟了。示波器一抓上下桥臂的栅极波形，问题一目了然：本该错开的一对互补 PWM，在切换瞬间出现了几纳秒的重叠——上下管同时导通，电池包的母线电压直接"底朝天"短路，IGBT 当场炸裂。

这不是段子，而是每个玩过电机驱动、DCDC、或者 BMS 主动均衡的底层工程师都绕不开的坑。**PWM（Pulse Width Modulation，脉冲宽度调制）负责"稳准狠"地输出控制信号，而 ICU（Input Capture Unit，输入捕获单元）则负责"分毫不差"地测量外部信号。** 它们看似只是定时器模块的两个子功能，却一个管"输出控制"，一个管"输入测量"，合起来构成嵌入式系统与外部世界最朴素也最关键的定时接口。

在 BMS 里，PWM 用来驱动主动均衡电路、给风扇调速、甚至精确控制保险丝引爆脉冲的能量；ICU 则用来捕获碰撞信号的脉宽、测量旋转件的转速。理解它们，首先要理解定时器本身。

## 二、核心原理：定时器如何"数"出时间和占空比

定时器本质上是一个**自由运行的计数器**：一个时钟源（经分频）不断给一个 N 位计数寄存器 +1，溢出后归零。所有"时间相关"的功能都建立在这个计数器之上。

### 2.1 PWM 是怎么来的

PWM 输出由**比较匹配**产生。设想计数器从 0 累加到自动重装载值 `ARR`（Auto Reload Register），周而复始；同时有一个比较寄存器 `CCR`（Capture/Compare Register）。当计数值小于 `CCR` 时输出高，大于等于 `CCR` 时输出低（极性可配），于是：

- 周期 `T = (ARR + 1) / f_tim`
- 高电平时间 `Ton = (CCR + 1) / f_tim`
- 占空比 `D = CCR / ARR`

分辨率（占空比可调的精细度）等于 `log2(ARR+1)`，16 位定时器就是 65536 级。这就像用一个极快的秒表，在每一个计数周期里决定"亮多久、灭多久"。

**类比**：把 PWM 想象成水龙头的"开合节律"——你不需要连续控制水流，只要在一个固定周期里"开一段、关一段"，平均出水速率（等效电压/功率）就由开合的比例（占空比）决定。电机、加热丝、均衡电阻感受到的都是这个平均量。

### 2.2 死区（deadtime）：半桥的保命间隙

驱动半桥（上管、下管）必须用**互补 PWM**——上管开时下管关，反之亦然。但功率器件的关断比开通慢，若软件只做"你开我关"的理想切换，会出现**两者都未完全关断的重叠窗口**，母线经上下管直通短路。

解决方法是插入**死区（deadtime）**：在互补通道切换处，强制两路都输出关断电平一小段时间，确保"先关后开"。死区由定时器硬件自动插入（配置死区寄存器，单位通常是定时器时钟周期的倍数），不靠软件延时，因此精确且不受中断抖动影响。死区太短有直通风险，太长则输出畸变、效率下降——典型值在几十到几百纳秒。

> 互补 PWM 的死区示意：上下桥臂切换之间插入一小段"两管同关"的间隙，确保先关后开、避免直通短路。

### 2.3 ICU：让硬件替你掐表

ICU 的原理是：**在外部信号的边沿（上升/下降/双沿）到达的瞬间，硬件自动把当前定时器计数值锁存进捕获寄存器，并产生中断或 DMA 请求。** 软件只需在中断里读走这个时间戳，两时刻相减即得周期、脉宽、占空比。

对比"用 GPIO 中断 + 软件读定时器"：中断有延迟、有抖动（受关中断、高优先级任务影响），ICU 是**纳秒级的硬件锁存**，精度高且几乎不占 CPU。测量高频时还可配合定时器溢出计数（溢出次数 × 周期 + 捕获值）。

**类比**：ICU 像是田径场上每个计时点都有摄像头自动拍照（硬件锁存），而不是靠人眼看到再按秒表（软件中断）。

> ICU 输入捕获测脉宽流程：硬件在信号边沿瞬间锁存定时器计数值，软件用三次边沿时间戳计算周期与占空比。

```mermaid
flowchart LR
  A[等待上升沿] -->|边沿到达| B[硬件锁存 t1<br/>当前计数值]
  B --> C[等待下降沿]
  C -->|边沿到达| D[硬件锁存 t2]
  D --> E[等待下一上升沿]
  E -->|边沿到达| F[硬件锁存 t3]
  F --> G[计算: 周期 T=t3-t1<br/>脉宽=t2-t1<br/>占空比=(t2-t1)/T]
  G --> A
```

## 三、帧格式 / 寄存器位域与配置

### 3.1 PWM 关键参数（逐字段）

| 参数 | 含义 | 关系 |
|------|------|------|
| `f_tim` | 定时器时钟（经预分频） | 决定计数节拍 |
| `ARR` | 重装载值，定周期 T | `T = (ARR+1)/f_tim` |
| `CCR` | 比较值，定高电平 Ton | `D = CCR/ARR` |
| `Deadtime` | 互补通道间都关的间隙 | 防上下管直通 |
| 极性 | 高/低有效 | 决定 Ton 在哪段 |
| 对齐 | 边沿/中心对齐 | 影响谐波与对称 |

### 3.2 ICU 测量（逐字段）

用 ICU 测一个周期信号：上升沿捕获 `t1`、下降沿捕获 `t2`、下一上升沿捕获 `t3`。
- 周期 `T = t3 - t1`
- 脉宽 `= t2 - t1`
- 占空比 `= (t2 - t1) / T`
- 频率 `= 1 / T`

### 3.3 配置代码片段（以通用定时器 IP 为例，伪代码）

```c
/* PWM：定时器1 通道1 输出 20kHz，占空比 40%，配对互补通道带死区 */
PWM_TimerInit(TIM1, .prescaler = 0, .arr = 3999, .mode = EDGE_ALIGN);
/* f_tim 假设 80MHz → T = 4000/80M = 50us → 20kHz */
PWM_ChannelConfig(TIM1, CH1,
    .ccr    = 1600,          // 1600/4000 = 40% 占空比
    .polarity = HIGH_ACTIVE,
    .complementary = ENABLE);
PWM_DeadtimeConfig(TIM1, .deadtime_ns = 200);  // 200ns 死区
PWM_Start(TIM1, CH1);

/* ICU：定时器2 通道1 捕获上升沿与下降沿，测周期/占空比 */
ICU_Init(TIM2, .prescaler = 79);   // 80MHz/80 = 1MHz，1us 分辨率
ICU_ChannelConfig(TIM2, CH1,
    .edge = BOTH_EDGE,        // 双边沿捕获
    .prescaler = 0,
    .filter = 4);             // 数字滤波抗抖
ICU_EnableInterrupt(TIM2, CH1, .callback = OnCapture);
```

回调中维护状态机：第一次上升沿记 `t1`、下降沿记 `t2`、第二次上升沿算 `T` 与占空比。

## 四、BMS 场景：从均衡到引爆

- **主动均衡驱动**：用 PWM 给变压器/电感充电，占空比控制转移能量大小；需配合电流采样做闭环，避免过充。
- **风扇调速**：占空比调转速，温度阈值保护，PWM 频率要避开可闻噪声（>20kHz）。
- **保险丝/Pyro  fuse 引爆**：这是最讲究的——用精确脉宽控制通过火工品的能量，过短不引爆、过长有危险，往往走独立高可靠定时器通道并加硬件互锁。
- **碰撞信号检测（ICU）**：碰撞传感器输出特定脉宽/频率脉冲，ICU 捕获后判定是否真实碰撞，触发断高压（HVIL 联动）。这里 ICU 的硬件锁存精度直接决定能否在毫秒级可靠响应。

### 4.1 中心对齐 PWM 与谐波

PWM 除了"边沿对齐"（计数器从 0 涨到 ARR，到 CCR 翻转为高），还有**中心对齐（Center-aligned）**模式：计数器先涨后落，在中间值附近翻转，使两路互补输出的跳变关于原点对称。中心对齐的优势是输出波的谐波能量更分散、EMI 更低，且上下管死区对称——电机驱动、DCDC 常用。代价是有效频率减半（每周期计两趟），配置时要按"中心对齐下 ARR 对应半周期"来算。BMS 主动均衡的变压器驱动若用 PWM，频率与对齐方式直接影响铁损与效率。

### 4.2 定时器时钟树与预分频

新手常忽略：PWM 频率不是"想设多少设多少"，它受定时器时钟树约束。定时器时钟来自总线时钟经预分频（prescaler）分频，再喂给计数器。`f_tim = f_bus / (PSC+1)`，周期 `T = (ARR+1)/f_tim`。要得到非整数分频比的频率（比如 18.3kHz），需权衡 PSC 与 ARR 组合，并接受微小偏差；同时高分辨率要求 ARR 尽量大，这又挤压了最高频率。工程选型时先定"最高频下限"和"最低分辨率下限"，反推所需定时器时钟。

## 五、常见坑与调试手段

1. **死区时间不足或过长**：不足→半桥直通炸管；过长→输出不对称、效率下降。调试用示波器双通道同时抓上/下桥臂栅极，量重叠区。务必确认死区是**硬件插入**而非软件延时。
2. **占空比分辨率不足**：高频下 `ARR` 被迫很小，占空比级数骤降，控制精度差。对策：提高 `f_tim`（降预分频）或降 PWM 频率，或选更高位定时器。
3. **ICU 测量受中断抖动污染**：在中断里做复杂运算导致下一边沿丢捕获。对策：用 DMA 搬捕获值、或中断里只存时间戳，运算放任务级；高频信号加数字滤波 (`filter`) 抗毛刺。
4. **互补通道极性配反**：导致"该关时开着"，逻辑分析仪抓波形对照手册符号最快定位。
5. **定时器时钟源选错**：用错内部/外部时钟或预分频算错，频率整体偏差。先确认 `f_tim` 再算 `ARR/CCR`。

## 六、面试高频要点

- **PWM 的占空比怎么计算？** → `D = CCR / ARR`，由比较寄存器与重装载值比值决定；频率由 `ARR` 与定时器时钟决定。
- **死区（deadtime）为什么必须？** → 半桥上下管关断速度不一致，若无死区会出现同时导通→母线直通短路；死区强制两管都关一小段确保先关后开。
- **ICU 比"GPIO 中断 + 软件读定时器"好在哪？** → 硬件在边沿瞬间锁存计数值，不受中断延迟/抖动影响，精度高且不占 CPU。
- **BMS 里 PWM/ICU 分别干什么？** → PWM 输出驱动（主动均衡/风扇/保险丝引爆），ICU 输入测量（碰撞信号脉宽、转速）。
- **分辨率和精度是一回事吗？** → 不是。分辨率是 `log2(ARR+1)`（能分多少级），精度还受死区、时钟抖动、滤波器影响。
