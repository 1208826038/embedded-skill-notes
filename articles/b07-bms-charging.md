# BMS 进阶（七）· 充电策略与快充管理

> 充电是用户每天高频触碰的环节，也是**老化和安全的最大变量**。慢充伤不起时间，快充伤不起电池。BMS 的充电管理就是在"速度、寿命、安全"三角里找最优。你已有的 `10-bms-system.md` 没专门讲充电策略，这一章补上。

---

## 一、充电的基本曲线：CC / CV

最经典的是**恒流恒压（CC-CV）**：

1. **CC 段（恒流）**：电压低于阈值前，以恒定电流（如 0.5C~1C）充，电压线性上升。此段贡献大部分电量，决定速度。
2. **CV 段（恒压）**：电压到达上限（如 4.2V/电芯）后保持电压，电流自然衰减。此段"收尾"，把最后 10~20% 充满，但耗时长、产热多。
3. **截止**：电流 < 某阈值（如 0.05C）判定充满。

> 痛点：CV 段又慢又热。快充的精髓就是**在不到 CV 的边界里尽可能多塞电流，同时不触发析锂**。

---

## 二、快充的核心约束：别析锂

快充最危险的副反应就是**析锂**（第 3 章讲过：锂离子来不及嵌入负极而镀在表面）。析锂三要素：**大电流、低温、高 SOC**。

BMS 快充必须建立"析锂边界"：

- **电流上限随温度/SOC 动态降额**：
  - 低温（<0℃）：几乎不能快充（析锂风险极高），先加热再充。
  - 常温：可 1C~3C。
  - 高 SOC（>80%）：接近析锂边界，电流必须大幅降（进入"伪 CV"）。
- **负极电位监测（高级）**：部分方案用参比电极/模型估算负极电位，一旦逼近析锂电位立即降流——这是学术界快充最优解，车端因成本和可靠性还少落地。

```c
/* 快充电流查表降额（示意） */
float fastcharge_current_limit(float soc, float temp)
{
    if (temp < 0.0f)   return 0.0f;            /* 先加热 */
    if (temp < 10.0f)  return 0.3f * C_RATE;   /* 低温限流 */
    if (soc > 0.8f)    return 0.3f * C_RATE;    /* 高 SOC 限流 */
    if (soc > 0.6f)    return 0.6f * C_RATE;
    return 1.5f * C_RATE;                       /* 常温中段可快充 */
}
```

## 三、热感知充电（Thermal-Aware Charging）

把第 5 章的热模型接进来：充电电流不只是 SOC/温度查表，而是**优化"在热约束内最快充满"**。

- 思路：用模型预测"若以电流 I 充 t 秒，温度会到多少"，把温升速率、最高温纳入约束，解一个小型最优控制问题（模型预测控制 MPC 思路）。
- 工程简化版：温度 > T1 降流、> T2 暂停充电并开液冷；配合预热水循环（低温充电前先加热到适宜温区）。

---

## 四、多段 / 智能充电

- **阶梯充电**：把 CC 段拆成几段递减电流（如 3C→2C→1C），兼顾速度与析锂。比单纯 CC-CV 快且不超边界。
- **脉冲充电**：间歇大电流 + 短暂休止/反向脉冲，给极化"喘息"，可缓解析锂、降低温升，但电路复杂。
- **自适应充电（数据驱动）**：用车云回传的该电池健康状态，动态调整充电曲线——健康差的老电池自动降速，延长寿命。

---

## 五、充电协议接口：GB/T 27930（中国国标）

中国电动汽车直流快充遵循 **GB/T 27930**（与 GB/T 20234 插头、GB/T 18487 总体要求配套）。BMS 在充电中是**被控对象 + 协商者**，通过 CAN 与充电桩（CCS/Charge Point）通信：

关键报文（简化）：
- **CHM/CRM**：握手（充电桩 ↔ BMS 辨识）。
- **BCP/BRO**：配置（充电参数、准备就绪）。
- **BCL（核心）**：BMS 实时下发**需求电压/需求电流**——充电功率由 BMS 说了算（基于上述充电策略算出来的限值）。
- **BCS**：BMS 上报实际电压/电流/SOC/状态。
- **BST/BSD**：充电结束（正常/故障）。

> BMS 的核心职责：**根据电池状态算出"现在能要多少电流电压"，通过 BCL 告诉桩，并实时监控桩是否超限（超了立即 BST 终止）**。

---

## 六、交流慢充（车载充电机 OBC）

交流慢充由车内 OBC 整流，BMS 只管"电池侧"：接收 OBC 送来的电流，做 SOC/温度/电压保护，通过 CAN 给 OBC 下达充电允许与限值。逻辑同快充但电流小、时间长，析锂风险低。

---

## 七、充电相关诊断与安全

- **过充保护**：任何充电阶段电压逼近上限必须降流/截止；电压超硬阈值立即断接触器。
- **充电中热失控**：充电是热失控高发场景（大电流+满电），必须叠加第 5 章的 dT/dt 预警。
- **通信丢失**：BCL 通信中断 → 桩应自动降流/停机；BMS 侧超时判定故障。
- **插头温度监控**：充电枪/座温感，超温降额（枪头过热是常见快充限制因素）。

---

## 八、常见坑

1. **低温直接快充析锂**：不加热就给大电流 → 析锂 → 容量永久损失甚至枝晶刺穿。必须先热管理。
2. **CV 段硬灌**：为赶时间 CV 段还强推电流 → 必然析锂。CV 必须自然衰减。
3. **BCL 限值算错**：SOC/温度降额逻辑 bug → 给桩发了超边界电流 → 过充。BCL 是安全关键，须 ASIL 保护 + 硬限幅。
4. **只管电池不管枪温**：电池没事但枪头过热熔断，体验崩。需枪温联动。
5. **快充曲线不随老化更新**：老电池该降速却沿用新车曲线 → 加速衰减。应接 SOH 自适应。
6. **充满后不及时断**：长期浮充（100% 满电静置）加速 SEI 增长。建议"日常充到 80~90%"，长途才满充。

---

## 九、面试要点

- **CC-CV 各段做啥？** CC 恒流快速补电、CV 恒压收尾、电流衰减到阈值判满。
- **快充为什么怕低温？** 低温锂离子迁移慢，大电流易析锂（镀负极），损容量且有安全风险。
- **BMS 在 GB/T 27930 里干什么？** 通过 BCL 实时下发需求电压/电流（基于策略算限值），并监控桩是否超限。
- **热感知充电是什么？** 把热模型纳入约束，在温升/最高温限制内优化最快充满。
- **怎么缓解快充老化？** 温度/SOC 动态降额、阶梯/脉冲充电、SOH 自适应、避免长期满电。
- **为什么不建议天天充到 100%？** 长期高 SOC 加速 SEI 增长与析锂，日常 80~90% 更护电池。
