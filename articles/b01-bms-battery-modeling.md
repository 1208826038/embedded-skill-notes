# BMS 进阶（一）· 电池等效电路模型与参数辨识

> 本章是后面所有估计算法的"地基"。SOC、SOH、SOP、均衡、热管理，没有一个能离开一个准确的电池模型。如果你只记得一句：**模型不准，上层算法全是空中楼阁**。

---

## 一、为什么 BMS 必须有一个"电池模型"

先抛一个场景：你想算 SOC（剩余电量），最朴素的方法是安时积分 `SOC = SOC0 - ∫I dt / Q`。但问题来了：

- 容量 `Q` 会随温度、老化变化；
- 电流积分有零点漂移，跑几小时就偏了；
- 你不知道"当前电压到底对应多少电量"，没法校准。

要回答"电压 ↔ 电量"的映射、要预测"我再放 10A 电流电压会掉多少"，就必须有一个**能把电流、电压、SOC 串起来的数学模型**。这就是电池等效电路模型（Equivalent Circuit Model, ECM）的价值。

**类比**：电池就像一个"带弹簧和阻尼的油箱"。你往里灌油（充电）/放油（放电）的速率（电流）决定了油位变化（SOC），但油位计读数（端电压）还会被"弹簧回弹"（极化）和"管路阻力"（内阻）干扰。等效电路模型就是把这些物理直觉变成可计算的电路。

---

## 二、OCV–SOC 曲线：模型的灵魂

开路电压（Open Circuit Voltage, OCV）是电池在**静置、无电流**时的端电压，它是 SOC 的（近似）单值函数：`Vocv = f(SOC)`。这条曲线是 SOC 估计的"罗盘"。

### 2.1 几个关键特征

- **平台区与陡降区**：磷酸铁锂（LFP）OCV 曲线非常平（平台区宽），同样 20mV 误差对应很大 SOC 误差——这是 LFP 难用 OCV 标定 SOC 的根本原因。三元（NMC）曲线更陡，OCV 标定更友好。
- **滞回（Hysteresis）**：同一个 SOC，充电得到的 OCV 比放电得到的略高（约 10~30mV）。忽视滞回会让 SOC 在充放电切换时"跳一下"。工程上常用一阶滞回模型修正：`Vocv = f0(SOC) + h(SOC)·η`，其中 `η ∈ [-1,1]` 随电流方向变化。
- **温度依赖**：低温下 OCV 曲线整体偏移、容量缩水。OCV 表通常按温度分档（如 −20/0/25/45℃ 各一张）。

### 2.2 怎么拿到这条曲线

用 **GITT（准静态充放电，Galvanostatic Intermittent Titration Technique）**：充/放一小步 → 静置足够久（让极化消失）→ 记录稳态电压。逐点扫出 `Vocv(SOC)`。工程上常用多段脉冲 + 长静置近似。

## 三、等效电路模型家族

从简到繁，主流有这几档：

### 3.1 Rint 模型（内阻模型）

```
    + ──── [ R0 ] ──── OCV ──── -
```

`V = OCV(SOC) - I·R0`（放电 I>0）

- 优点：极简，一个参数 R0。
- 缺点：没有"极化"概念，电流突变后电压瞬间跳变，不符合真实电池的**弛豫过程**。只能做粗略估算。

### 3.2 Thevenin 模型（1RC）

```
    + ──[R0]──┬──[R1]──[C1]──┬── OCV ── -
              │              │
```

状态方程：

```
ṠOC = -I / Q
V1_dot = -V1/(R1·C1) + I/C1
V  = OCV(SOC) - I·R0 - V1
```

- `R1//C1` 模拟**极化**（电荷在电极/电解液界面的积累与释放），让电压变化有"惯性"。
- 这是工程里**最常用**的折中：够准、参数少、好做卡尔曼滤波。

### 3.3 双 RC / PNGV 模型

在 Thevenin 基础上再加一级 RC（2RC），或更早的 PNGV 模型（用一个电容代表 SOC 累积、一个 RC 代表极化）。2RC 对动态工况（如 NEDC/WLTC 整车循环）拟合更好，但参数多一倍。

### 3.4 电化学模型（SPM / PDE）

从电极扩散方程出发（单粒子模型 SPM、伪二维 P2D）。精度最高、能反映析锂边界，但计算量太大，一般**离线仿真/电芯开发**用，车端 BMS 几乎不用。

> **选型建议**：车端 BMS 默认 Thevenin(1RC)，对动态要求高的用 2RC；资源紧张的从控可用 Rint 做粗算。

| 模型 | 参数 | 精度 | 算力 | 适用 |
|---|---|---|---|---|
| Rint | R0 | 低 | 极低 | 粗略估算/从控 |
| Thevenin 1RC | R0,R1,C1 | 中高 | 低 | **车端主选** |
| 2RC / PNGV | R0,R1,C1,R2,C2 | 高 | 中 | 高精度/仿真 |
| 电化学 | 数十 | 极高 | 高 | 电芯研发 |

## 四、状态空间离散化（给卡尔曼滤波铺路）

以 1RC 为例，写成离散状态空间（采样周期 Ts）：

```
x_k = [SOC_k, V1_k]^T

SOC_k = SOC_{k-1} - (Ts/Q)·I_{k-1}
V1_k  = exp(-Ts/(R1·C1))·V1_{k-1} + R1·(1-exp(-Ts/(R1·C1)))·I_{k-1}

V_k = OCV(SOC_k) - I_k·R0 - V1_k + w_k   (w 为测量噪声)
```

这里的 `OCV(SOC)` 通常查表 + 线性插值，或用多项式拟合 `OCV = a0 + a1·SOC + ... + an·SOC^n`。

> 注意 `OCV(SOC)` 是非线性的，所以后面的 SOC 估计要用**扩展卡尔曼滤波（EKF）**而不是普通 KF。

## 五、参数辨识：模型参数从哪来

模型有了，参数（`R0, R1, C1, OCV 表`）必须准确地"标"出来，否则模型是摆设。分**离线**和**在线**两条路。

### 5.1 离线辨识：HPPC + GITT

**HPPC（混合脉冲功率特性, Hybrid Pulse Power Characterization）** 是行业标配：

1. 在某 SOC 点，先放一个短时大脉冲（如 10s, 1C），再静置；
2. 放电瞬间的电压跌落 `ΔV / I` ≈ `R0`（欧姆内阻）；
3. 脉冲结束后电压按 RC 曲线回升，对回升段做指数拟合 → 解出 `R1, C1`；
4. 扫过 SOC 0~100%，得到 `R0(SOC), R1(SOC), C1(SOC)` 查表。

**GITT** 给出 OCV 表（见第二节）。两者结合，一张完整的参数表就齐了。

> 工程坑：HPPC 脉冲后静置时间不够，RC 没放完 → `C1` 估小；脉冲太短电流采样不准 → `R0` 估错。静置 ≥ 3τ（τ=R1·C1）才稳。

### 5.2 在线辨识：FFRLS

电池用着用着参数会变（老化、温度变化）。在线辨识让模型"自我更新"。

**带遗忘因子的递推最小二乘（FFRLS, Forgetting Factor RLS）** 是工程首选：

```
把 1RC 观测式写成回归形式：
V_k + (α-1)·V_{k-1} = θ0·OCV_k + θ1·V1_{k-1} + θ2·I_k + θ3·I_{k-1} + e_k
其中 α = exp(-Ts/(R1·C1))，未知参数含 R0,R1,C1。

递推：
K_k = P_{k-1}·φ_k / (λ + φ_k^T·P_{k-1}·φ_k)
θ_k = θ_{k-1} + K_k·(y_k - φ_k^T·θ_{k-1})
P_k = (I - K_k·φ_k^T)·P_{k-1} / λ
```

`λ ∈ (0,1]` 为遗忘因子（如 0.98~0.999），越小越"喜新厌旧"，能跟踪慢时变但抗噪差。

## 六、C 代码落地（1RC 模型 + FFRLS 骨架）

```c
/* 1RC 模型参数（查表后代入） */
typedef struct {
    float R0;     /* 欧姆内阻   */
    float R1;     /* 极化电阻   */
    float C1;     /* 极化电容   */
    float Q;      /* 容量 Ah    */
    float Ts;     /* 采样周期 s */
} ecm_1rc_t;

/* 离散更新：给定上一状态与电流，算出新 V1 与预测端压 */
void ecm_step(const ecm_1rc_t *m, float soc_prev, float v1_prev,
              float I, float *soc_new, float *v1_new, float *v_pred)
{
    float a = expf(-m->Ts / (m->R1 * m->C1));
    *soc_new = soc_prev - (m->Ts / (m->Q * 3600.0f)) * I; /* Q 换算到 As */
    *v1_new  = a * v1_prev + m->R1 * (1.0f - a) * I;
    *v_pred  = ocv_lookup(*soc_new) - I * m->R0 - *v1_new; /* OCV 查表 */
}

/* FFRLS 在线辨识（简化标量版，实际用向量 θ=[R0,R1,C1]） */
#define LAMBDA 0.99f
static float P = 1.0f, theta = 0.05f; /* 初始 R0 估计 */
void ffrl_s_step(float y, float phi, float *theta_out)
{
    float K = P * phi / (LAMBDA + phi * P * phi);
    theta  = theta + K * (y - phi * theta);
    P      = (1.0f - K * phi) * P / LAMBDA;
    *theta_out = theta;
}
```

> 真实工程里 `θ` 是 3~4 维向量、P 是矩阵（用 3×3），BMS 主控 MCU（Cortex-R）跑得动；从控算力不够时只做 R0 在线跟踪即可。

## 七、常见坑（血泪清单）

1. **温度没做分档**：一张 25℃ 参数表用到 −10℃，电压预测偏几十 mV。
2. **忽视滞回**：充放电切换 SOC 跳变，仪表盘电量"蹦迪"。
3. **参数不随 SOC 更新**：只在满电标一次，低 SOC 区 R0 翻倍却仍用旧值。
4. **采样噪声没滤波**：电流霍尔噪声直接进辨识 → θ 抖成筛子。先对 I/V 做滑动平均/低通。
5. **辨识初值敏感**：FFRLS 初值给得太离谱，前几十秒收敛乱跳。给合理初值 + 收敛期冻结输出。
6. **OCV 表插值越界**：SOC 积分跑到 1.02 或 −0.01，查表越界返回乱值 → 端压预测崩。必须 clamp。

## 八、面试要点

- **Rint 和 Thevenin 差在哪？** Rint 无极化、电压瞬变；Thevenin 多一个 RC 模拟弛豫，更接近真实动态。
- **为什么车端多用 1RC 而不是电化学模型？** 电化学算力太高、实时性不达标；1RC 精度够、参数少、好做 EKF。
- **HPPC 怎么做？** 定点脉冲 + 长静置，从瞬落取 R0、从回升指数拟合取 R1/C1，扫 SOC 建表。
- **在线辨识为什么用带遗忘因子的 RLS？** 电池参数慢时变，遗忘因子让算法跟踪变化又抗噪。
- **OCV 滞回怎么处理？** 加一阶滞回项 `h(SOC)·η`，η 随电流方向更新。
- **LFP 为什么难用 OCV 标定 SOC？** 平台区太平，电压误差直接放大成 SOC 误差；只能靠安时积分 + 满充校准。
