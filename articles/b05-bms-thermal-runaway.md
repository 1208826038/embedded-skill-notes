# BMS 进阶（五）· 电池热建模与热失控传播防护

> 你已有的 `10-bms-system.md` 把"热管理"作为接口一笔带过。但热，是动力电池安全的命门：过温不处理 → 热失控 → 烧车。这一章讲**热从哪来、怎么建模、怎么控、失控了怎么防蔓延**。这是 BMS 安全责任里最硬的一块。

---

## 一、热量从哪来：产热模型

电池充放电时内部产热，主要来自三处：

1. **焦耳热（I²R）**：电流流经内阻 `R0` 的欧姆热，`Q_joule = I²·R0`。大电流（快充/急加速）时主导。
2. **极化热**：电极/界面极化（`R1` 部分）的不可逆热，与电流、SOC 相关。
3. **熵热（可逆热）**：电化学反应本身吸热或放热，`Q_ent = I·T·(dOCV/dT)`。充放电方向相反（充电可能吸热、放电放热），量通常小于焦耳热但低温下不可忽略。

**总产热（单体）**：`Q_gen = I²·R0 + I²·R1·(某系数) + I·T·(dOCV/dT)`

> 工程简化：多数 BMS 热模型只抓 `I²R` 主导项，配合温度采样做闭环控制，不追求精确产热分解。

---

## 二、集总参数热模型（Lumped Thermal Model）

把一节/一模组看成一个均匀温度节点（忽略内部梯度），用一阶热网络：

```
C_th · dT/dt = Q_gen - h·A·(T - T_amb)      // 自然/强制对流散热
            = Q_gen - (1/R_th)·(T - T_cool)  // 液冷：R_th 为到冷却液热阻
```

- `C_th`：热容（电芯质量×比热）。
- `R_th`：热阻（到环境/冷却液）。
- `T_cool`：冷却液/环境温度。

**多节点模型**：把"电芯—壳体—冷却液"做成 2~3 节点，能模拟"电芯热了先传给壳、再被液冷带走"的延迟，对热失控预警更准。

```c
/* 一节点热模型离散更新（秒级） */
float dT = (Q_gen - (T - T_cool)/R_th) / C_th;
T_next  = T + dT * Ts;
```

## 三、热管理执行：风冷 vs 液冷

| 方式 | 原理 | 优点 | 缺点 | 适用 |
|---|---|---|---|---|
| 风冷 | 风扇强制对流 | 简单便宜 | 均温差、散热上限低 | 低端/小倍率 |
| 液冷 | 水冷板贴模组 | 散热强、均温好 | 系统复杂、漏液风险、贵 | 乘用车主流 |
| 冷媒直冷 | 制冷剂进板 | 效率最高 | 控制复杂 | 高端/快充平台 |
| 相变材料(PCM) | 吸热相变 | 被动均温 | 成本高、可逆性 | 辅助 |

BMS 角色：根据温度/温升速率，**输出风扇占空比（PWM）或液冷水泵/压缩机请求（通过 CAN 给热管理控制器）**，并设温度门限（如 >45℃ 降功率，>55℃ 切断）。

## 四、热失控（Thermal Runaway）：最危险的失效

### 4.1 触发链

热失控是**链式放热反应**自我加速：温度升高 → SEI 膜分解 → 负极与电解液反应放热 → 隔膜熔化短路 → 正极分解放氧 → 电解液燃烧……温度可在秒级冲到 500~1000℃，并喷出可燃气体。

常见触发源：
- **机械滥用**：碰撞/针刺，内部短路。
- **电滥用**：过充（正极析氧）、过放（铜枝晶）、外短路（超大电流）。
- **热滥用**：高温环境、局部过热（如某芯热失控引燃邻居）。

### 4.2 表征参数

- **T1（自产热起始）**：~80~90℃，SEI 开始分解。
- **T2（热失控触发）**：~120~140℃，隔膜熔化、内短路，温升速率突变（dT/dt 陡增是预警金指标）。
- **T3（最高温度）**：失控峰值。

## 五、热蔓延（Propagation）防护——GB 38031 核心

单芯失控不可完全避免，关键是**不让它烧到隔壁**。国标 **GB 38031《电动汽车用动力蓄电池安全要求》** 要求：电池包在热失控后**5 分钟内不起火不爆炸**（给乘员逃生时间），并具备热事件预警。

防护手段（BMS + 结构协同）：
1. **隔热**：电芯间气凝胶/云母/陶瓷毡，阻断热传导。
2. **排气通道**：定向泄压，把可燃气体引到包外而非堆积。
3. **抑制材料**：阻燃泡棉、火灾抑制剂。
4. **早期预警**：监测 `dT/dt` 突变、单体电压骤降、包内压力/烟雾/VOC 传感器 → 提前数秒~数十秒报警。
5. **主动断路**：预警即断高压（接触器分断），防电弧扩大。

### BMS 预警算法骨架

```c
#define TRIGGER_dTdt  2.0f   /* ℃/s 异常温升阈值 */
#define TRIGGER_dV    0.3f   /* V 单体电压骤降 */
void thermal_event_check(float dTdt, float dv, bool *alarm)
{
    /* dT/dt 突变 + 电压同步下跌 = 强烈热失控特征 */
    *alarm = (dTdt > TRIGGER_dTdt) && (dv > TRIGGER_dV);
}
```

> 注意：`dT/dt` 单判易误报（快充大电流也会升温），必须**多特征融合**（温升速率 + 电压异常 + 气体/压力）才可靠。

## 六、常见坑

1. **只控最高温不管温差**：模组内部温差 >5℃ 会加速不一致老化；要控"最热芯"且关注"温差"。
2. **降功率门限设太高**：等到 55℃ 才动作，温升已失控。应按温升速率**提前**降功率。
3. **热模型参数不标定**：`C_th/R_th` 用 datasheet 估算，实际偏差大 → 预测温度与实际脱节。应在台架实测拟合。
4. **预警只看温度**：漏掉电压骤降/气体信号，真失控时反应慢半拍。多源融合才稳。
5. **隔热与泄压矛盾**：只堆隔热不设计排气，能量闷在包内反而更危险。
6. **液冷泄漏无检测**：冷却液进电芯 → 短路。需漏液检测 + 绝缘监控联动。

## 七、面试要点

- **产热三大来源？** 焦耳热 I²R、极化热、熵热（可逆），大电流时 I²R 主导。
- **集总热模型是什么？** 一阶热网络 `C·dT/dt = Q_gen − (T−T_amb)/R_th`，离散迭代预测温度。
- **热失控触发链？** 升温→SEI 分解→隔膜熔→内短路→正极放氧→燃烧，链式自加速。
- **GB 38031 核心要求？** 热失控后 5 分钟不起火不爆炸 + 热事件预警。
- **怎么防热蔓延？** 隔热+定向排气+抑制材料+早期多源预警+主动断高压。
- **预警为什么要多特征融合？** 单看 dT/dt 快充也会误报，需温升+电压+气体/压力联合判断。
