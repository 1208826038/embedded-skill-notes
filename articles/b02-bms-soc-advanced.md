# BMS 进阶（二）· SOC 高精度估计算法：从安时积分到 EKF/UKF 与数据驱动

> 上一章你拿到了电池模型，这一章就用它把 SOC 算准。安时积分只是"记账"，真正的高精度 SOC 是**模型 + 滤波 + 校准**的组合拳。

---

## 一、安时积分的天然缺陷（为什么不能只靠它）

安时积分（Coulomb Counting）：

```
SOC(k) = SOC(k-1) - (η · I(k) · Ts) / (Q_nominal · 3600)
```

`η` 为库仑效率（≈0.99~1），`Q_nominal` 为额定容量。

问题：
- **误差累积**：电流零点漂移、采样量化误差，积分一路滚雪球，几小时就偏 5%+。
- **初始值未知**：上电时 SOC 是黑盒，必须靠 OCV 或满充校准"定锚"。
- **容量会变**：低温、老化让 `Q` 缩水，用额定容量算必偏。

结论：安时积分是**主体**（实时、无噪声放大），但必须配**校正机制**随时纠偏。

---

## 二、OCV 校正（最朴素的纠偏）

静置足够久 → 测端压 → 反查 OCV 表 → 得到参考 SOC → 把积分值"扳"回去。

- 触发条件：长时间无电流（静置）或小电流。
- 工程实现：检测到 `|I| < I_thr` 持续 T 秒，取平均电压查表刷新 SOC。
- 局限：**LFP 平台区太宽，OCV 校正分辨率差**；车在跑几乎没静置机会。

---

## 三、扩展卡尔曼滤波（EKF）：行业主路由

把上一章的 1RC 离散模型搬进来，EKF 在"预测（安时积分往前推）"和"更新（用实测电压修正）"之间反复横跳，天然抑制累积误差。

### 3.1 算法骨架

```
状态 x = [SOC, V1]
预测：
  x̂⁻_k = f(x̂⁺_{k-1}, I_{k-1})      // 模型向前推一步
  P⁻_k  = A_k · P⁺_{k-1} · A_kᵀ + Q  // 误差协方差传播
更新：
  y_k   = V_meas - h(x̂⁻_k, I_k)     // 新息（实测-预测电压）
  S_k   = H_k · P⁻_k · H_kᵀ + R
  K_k   = P⁻_k · H_kᵀ · S_k⁻¹       // 卡尔曼增益
  x̂⁺_k  = x̂⁻_k + K_k · y_k          // 修正
  P⁺_k  = (I - K_k·H_k) · P⁻_k
```

- `A_k = ∂f/∂x`（雅可比），`H_k = ∂h/∂x`（OCV 对 SOC 的导数 + 对 V1 的偏导）。
- `Q` 是过程噪声（模型不确定），`R` 是测量噪声（电压传感器）。**调参核心就是 Q/R 比值**：R 相对大 → 更信模型、SOC 平滑但纠偏慢；R 小 → 更信电压、响应快但易被噪声带偏。

### 3.2 C 落地要点

```c
/* EKF 1RC 核心（标量示意，真实用 2x2 矩阵） */
/* 预测 */
soc_pred = soc_est - (Ts/(Q*3600.0f))*I;
v1_pred  = a*v1_est + R1*(1-a)*I;
v_pred   = ocv(soc_pred) - I*R0 - v1_pred;
/* 新息与增益 */
innov    = V_meas - v_pred;
K_soc    = P_soc / (P_soc + R_volt);   /* 简化标量增益 */
soc_est  = soc_pred + K_soc * innov;
P_soc    = (1 - K_soc) * P_soc + Q_proc;
```

### 3.3 常见坑

- **雅可比算错**：OCV 导数用错符号/数量级，增益发散 → SOC 冲到 2.0。务必核对 `dOCV/dSOC` 的正负号与量级（mV/%）。
- **Q/R 失衡**：R 太小，电压噪声被当真 → SOC 抖动；R 太大 → 不纠偏，回到安时积分老路。
- **数值爆炸**：P 矩阵不约束，长时间跑溢出。加 `P = clamp(P, Pmin, Pmax)`。
- **初值离谱**：上电给 0.5 但实际 0.9，前几分钟猛追。先用 OCV 粗定锚再进 EKF。

## 四、无迹卡尔曼滤波（UKF）：非线性更强

EKF 用一阶泰勒展开近似非线性（OCV 曲线），误差来自"线性化截断"。**UKF 用无迹变换（UT）** 选一组"sigma 点"过真实非线性函数再统计，对强非线性（陡 OCV、滞回）更稳，代价是多算 2n+1 个点（n=2 时也就 5 个点，算力可接受）。

> 工程取舍：1RC + 平滑 OCV 下 EKF 足够；若用 2RC + 强滞回 + LFP，UKF 鲁棒性更好。

---

## 五、联合估计算法（SOC + 参数一起估）

前面参数用 FFRLS 单独在线辨，SOC 用 EKF 单独估——两路独立。更先进的是**双扩展卡尔曼（DEKF）/联合状态扩充**：把 `R0,R1,C1` 也放进状态向量一起估。好处是参数和 SOC 互相耦合修正（电压残差同时修正 SOC 和参数），坏处是状态维数高、实现复杂、易发散。

工业主流仍是**"FFRLS 辨参数 → EKF 估 SOC"** 解耦架构，简单可靠。

## 六、数据驱动 / 机器学习路线（行业新趋势）

当"第一性原理"模型在极端工况（低温、老化、LFP 平台区）不够用时，数据驱动补位：

| 方法 | 思路 | 优劣 |
|---|---|---|
| ANN（神经网络） | 输入 I/V/T/历史 → 直接回归 SOC | 拟合强，需大量数据，黑盒难解释 |
| SVR（支持向量回归） | 小样本泛化好 | 训练慢，参数敏感 |
| 迁移学习 | 用大量电芯数据预训练，少量本车数据微调 | 解决"每辆车数据少"痛点 |
| 端到端 LSTM | 时序电流电压序列 → SOC | 抓长程依赖，算力大 |

**现实落地**：纯数据驱动很少单独上车（安全/可解释性要求高），多是**"物理模型为主 + 数据驱动做残差补偿/老化修正"** 的混合架构。

## 七、工程级 SOC 方案长什么样

```
              ┌─────────────┐
   电流 I ───▶│  安时积分    │──▶ SOC_raw
              └─────────────┘
                    │
        ┌───────────┼───────────────┐
        ▼           ▼               ▼
   静置OCV校正   EKF(模型+电压)   老化容量在线修正
        │           │               │
        └───────────┴───────────────┘
                    ▼
              SOC_final（多源融合，限幅[0,1]）
                    │
              输出 + 健康度/温度门限保护
```

- **多源融合**：安时积分为主，EKF 持续纠偏，静置 OCV 做"硬锚点"，老化容量在线更新。
- **安全门限**：SOC 接近 0/1 时强制限制放电/充电功率（配合 SOP，见后续章节）。
- **一致性处理**：单体 SOC 用从控算，包级 SOC 取均值/最小单体，避免"木桶效应"。

## 八、面试要点

- **为什么不能只靠安时积分？** 误差累积 + 初始值未知 + 容量随温/老化变。
- **EKF 相比纯安时积分强在哪？** 用电压测量反复校正，抑制累积误差，给出最优估计。
- **Q/R 怎么调？** R 大→信模型、平滑但纠偏慢；R 小→信电压、快但抖；按传感器噪声实测标定。
- **EKF 和 UKF 区别？** EKF 一阶线性化有截断误差，UKF 用 sigma 点过真实非线性更准。
- **数据驱动能单独上车吗？** 一般不能，安全/可解释性要求高，多作物理模型的补偿。
- **LFP 的 SOC 怎么搞？** OCV 平台太宽，靠"满充锚定 + 安时积分 + 基于模型/EKF 全程跟踪"，少依赖静置 OCV。
