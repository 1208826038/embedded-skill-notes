# BMS 进阶（四）· 主动均衡拓扑与控制策略

> 你已有的 `10-bms-system.md` 讲了"被动/主动均衡"的概念。这一章往深里钻：主动均衡**到底有哪几种电路拓扑、各自效率几何、控制算法怎么写、什么时候该均衡**——这是 BMS 硬件/算法工程师的分水岭。

---

## 一、为什么必须均衡

一节电芯 3.7V 2Ah，几十上百节串成包。出厂就存在 μΩ 级内阻、mAh 级容量差异，循环几百次后**不一致性放大**：容量最小的芯先放空（限功率）、容量最大的芯先充满（限充电）。不处理 → 整包可用容量被"最短木板"卡死，且过充/过放风险上升。

**均衡目标**：让各单体 SOC/电压趋于一致，释放整包容量、延长寿命、保障安全。

---

## 二、被动均衡：简单但有天花板

原理：对"电压最高"的单体并联电阻放电耗散，`P = V²/R`。

- 优点：电路极简（电阻 + MOSFET）、便宜、可靠、易诊断。
- 缺点：**能量直接变热浪费**；均衡电流小（百 mA 级），慢；只能"削峰"不能"填谷"，整包能量净损失。
- 适用：成本敏感、一致性好的场合（如低端储能、小包）。

---

## 三、主动均衡：把能量"搬"而不是"烧"

核心思想：在单体之间**转移能量**，而非耗散。速度快、效率高（>80%）、不浪费能量。拓扑是技术核心，主流有五类：

### 3.1 开关电容（Switched Capacitor）

相邻两节之间用电容 + 一组 MOS 开关，电容先接高压芯充电、再接到低压芯放电，反复"舀水"。

- 优点：拓扑简单、无磁性元件、天然只对相邻不均衡有效且自动平衡。
- 缺点：只能相邻传递，均衡速度受电容与开关频率限制；非相邻芯要"接力"多步。

### 3.2 飞返/反激（Flyback）变压器

用一个多绕组变压器，把所有单体绕组耦合到同一磁芯。控制开关，把能量从任意单体抽到总线再分配到需要的单体。

- 优点：**任意单体间可直接转移**，效率高、电流大。
- 缺点：变压器设计与驱动复杂，EMI 挑战，成本最高。

### 3.3 库克/升降压（Cuk / Buck-Boost）斩波

每节配一个 Cuk 或双向 Buck-Boost 模块，可在单体与母线间双向搬运能量。

- 优点：非相邻均衡、控制灵活、效率好。
- 缺点：每节一套功率器件，元件多、成本高、板面积大。

### 3.4 LC 谐振（Resonant）

利用 LC 谐振软开关降低开关损耗，适合中大电流，复杂度高。

### 3.5 变压器集中式（集中母线）

所有芯经各自原边绕组接到一个共享变压器，MCU 调度谁充谁放。

- 优点：调度全局最优（可一次把能量从最高芯搬到最低芯）。
- 缺点：变压器绕组多、驱动复杂。

| 拓扑 | 传递方式 | 效率 | 速度 | 复杂度/成本 |
|---|---|---|---|---|
| 被动电阻 | 耗散 | 0% | 慢 | 极低 |
| 开关电容 | 相邻电容 | 中高 | 中 | 低 |
| 飞返变压器 | 任意(磁耦合) | 高 | 快 | 高 |
| Cuk/升降压 | 单体↔母线 | 高 | 快 | 高 |
| LC 谐振 | 软开关 | 高 | 快 | 高 |
| 集中变压器 | 全局最优 | 高 | 快 | 高 |

## 四、均衡控制算法

硬件给了"搬运能力"，**何时搬、搬多少**靠算法。两派：

### 4.1 基于电压（Voltage-based）

最简单：监控各单体电压，谁比均值/最低值高 ΔV 就给谁放电（被动）或把谁的能量转出（主动）。

- 阈值：`V_cell > V_avg + ΔV_thr` 触发。
- 坑：**电压受负载/SOC 瞬时影响大**。大电流放电时，内阻大的芯电压偏低，若按电压均衡会"误伤"健康芯。所以均衡最好在**静置/小电流**时做，或改用 SOC 判据。

### 4.2 基于 SOC（SOC-based，推荐）

用前面章节的 SOC 估计，对 `SOC_cell > SOC_min + ΔSOC_thr` 的芯均衡。

- 比电压更本质：电压是 SOC 的带噪观测量，SOC 才是真目标。
- 触发：`max(SOC) - min(SOC) > ΔSOC_thr`（如 3%~5%）。

### 4.3 控制策略细节

- **均衡窗口**：充电末端（CV 段）最容易拉开差异，是被动均衡主战场；主动均衡可全程。
- **优先目标**：优先削最高芯（防过充）与填最低芯（防过放/释放容量）。
- **温度门限**：均衡发热，温度 > T_thr 暂停，防热失控风险。
- **调度算法（主动）**：集中式可做"全局最优分配"——构建能量转移矩阵，最小化总搬运次数/损耗。

```c
/* SOC 阈值均衡调度（骨架） */
#define SOC_BALANCE_THR 0.03f   /* 3% 差异触发 */
void balance_schedule(const float soc[], int n, bool ctrl[])
{
    float soc_min = soc[0], soc_max = soc[0];
    for (int i=1;i<n;i++){ if(soc[i]<soc_min)soc_min=soc[i]; if(soc[i]>soc_max)soc_max=soc[i];}
    float spread = soc_max - soc_min;
    for (int i=0;i<n;i++){
        ctrl[i] = (spread > SOC_BALANCE_THR) && (soc[i] > soc_min + SOC_BALANCE_THR);
        /* 主动均衡还可增加：把 ctrl[i] 的能量目标芯 = argmin(soc) */
    }
}
```

## 五、主动均衡的坑

1. **只看电压不看 SOC**：大电流下误均衡，越均衡越乱。改用 SOC 判据或静置均衡。
2. **均衡电流大却无温度保护**：主动均衡电流可达 A 级，发热集中，必须温度门限 + 限流。
3. **拓扑 EMI 不过车规**：变压器/开关电容高频开关，EMI 超标。需软开关/屏蔽/展频。
4. **效率被损耗吃掉**：变压器/开关有损耗，若搬运路径多跳（开关电容接力），总效率可能只剩 50%，不如设计好调度。
5. **均衡与采样打架**：均衡动作改变单体电压，此时采样值失真。均衡与采样时分复用或采样时暂停均衡。
6. **故障诊断缺失**：均衡 MOS/电容开路、短路无检测 → 悄悄失效。需均衡回路电流/温感监测。

## 六、选型建议

- **乘用车/高端储能**：主动均衡（飞返或 Cuk），释放容量、延长寿命，值回票价。
- **低端/小包/成本敏感**：被动均衡够用。
- **梯次利用/换电**：强均衡需求，主动是标配（要把不一致包"救活"）。
- 趋势：**模块化从控集成主动均衡 AFE**（如 TI BQ796xx 系列支持主动均衡驱动），软硬件一体化。

## 七、面试要点

- **被动 vs 主动本质区别？** 被动耗散能量（削峰），主动转移能量（削峰填谷），效率与速度天差地别。
- **开关电容为什么只能相邻均衡？** 电容只在相邻两节间"舀水"，非相邻要多次接力。
- **为什么均衡最好用 SOC 判据？** 电压受负载/SOC 瞬时噪声影响，大电流下会误均衡；SOC 才是真目标。
- **主动均衡最大的工程挑战？** EMI、热管理、效率损耗、故障诊断。
- **什么时候均衡最有效？** 充电 CV 末端（差异最大）、静置时；主动可全程。
- **为什么车规主动均衡要温度门限？** 均衡电流大发热集中，超温有热失控风险。
